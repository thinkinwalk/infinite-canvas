# 云端语音识别优化结果

代码已接入数字人视频学习和字幕识别的云端路线，识别模型不再必须加载到本机或网站服务器。正式云调用尚未启用：需要更新后端、配置可供供应商访问的公开 HTTPS 音频地址，并在管理员设置中启用模型和配置本站单价。本轮未部署生产、未产生付费识别任务。

## 实现

- 参考原文识别与字幕识别默认选择云端，保留处理服务识别选项；选择与任务输入通过原有 localforage 保存，刷新恢复。
- 接入 Replicate Incredibly Fast Whisper 固定版本 `3ab86df6c8f54c11309d4d1f930ac292bad43ace52d10c80d87eb258b3c9f79c`，自动检测原音频语言；参考原文请求词级时间戳，字幕请求分段时间戳。
- 网站只用 FFmpeg 提取单声道 16kHz MP3，并用 FFprobe 核对时长，不运行 Whisper。无音轨、提取失败与时长缺失在创建付费任务前拒绝，音频准备结果与普通人物视频参考分开缓存。
- 新增 JSON 文字/时间轴结果，按用户归属保存到平台任务并从鉴权结果接口读取；保留有效时间戳与完整识别文字，空文字或完全无有效时间轴按失败处理并沿用算力点返还逻辑。
- 管理后台新增识别模型。默认不启用、不预设价格；本站按管理员配置的输入音频秒数报价，沿用不足整秒向上取整、最低消费和用户分组倍率，上游运行时间费用独立核算。
- 沿用收费确认、幂等任务、停止等待、取消与恢复查询。明确创建失败且查询确认任务不存在时，清除未提交任务关联，避免余额不足后一直挂起；不明确的提交保留恢复查询，防止重复付费。
- 模型未开通会在上传前明确拦截；没有后台模型时不会静默切回本地或另建收费任务。

## 验证

`observations.json` 保存独立浏览器和模拟 API 观察：

- 未启用时拦截，尚未上传或创建任务。
- 报价确认可见，取消后没有创建任务。
- 音频准备使用 `purpose=transcribe`，提交给模型的是准备后的音频地址。
- 确认报价与提交点数一致；原文回填、刷新保留和字幕时间轴回填正常。
- 恢复已有任务没有创建新任务；本地路线刷新保留。
- 余额不足且服务端确认未创建任务时，页面不会留下不可恢复的待查询任务。
- 手机没有横向溢出，未观察到页面异常。

`audio-preparation.json` 保存真实 FFmpeg 观察：本地有声样片提取 MP3 成功，输出约 33KB；此前用户无音轨视频明确报告没有音轨且没有输出音频。本地样片是之前生成的 Windows TTS + 合成视频，不是云模型真实效果样片。

新增 Go 回归用例覆盖部分时间戳缺失、异常输出、默认不启用收费和音频秒数计算，按仓库要求未执行 Go 构建、语法检查或 Go 用例。尚未验证真实上游中文效果、耗时、费用、数据库结果保存、扣点/退款的后端端到端行为；模拟页面通过不等于后端或生产验收通过。

## 使用前与范围

1. 更新运行中的 Go 后端；数据库沿用现有自动建表逻辑增加任务 JSON 结果字段。
2. 配置 `PUBLIC_BASE_URL` 为供应商可访问的 HTTPS 地址，确认 FFmpeg/FFprobe 可执行。Docker 网站镜像已包含工具；Windows 开发环境可用 `FFMPEG_PATH` / `FFPROBE_PATH` 指向实际路径。
3. 在管理员设置的 Replicate 功能卡中配置语音识别单价和最低消耗，再启用。原 Replicate 服务端凭证继续复用，不向浏览器暴露供应商令牌。
4. 登录账号确认本次费用后执行。账号算力点不足会阻止实际创建收费任务；不能把典型供应商估价直接当作本站收费。

云端识别会发送音频到供应商，页面已说明。视频学习只识别人声，不识别画面字幕。剪气口当前仍在 worker 内部运行 Whisper；字幕烧录、配乐、首帧封面仍需要处理服务。后续可评估剪气口复用云端时间轴，不将本次变更描述为全部后期能力已经脱离处理服务。
