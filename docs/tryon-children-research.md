# 儿童模特与童装展示调研

## 当前实施范围

用户已将方案收敛为原模特分类中只增加“儿童”，不增加年龄段或额外设置。当前已完成本地实现：保留 51 位成人，按用户补充要求将儿童从 2 张扩充为男童、女童各 6 张嵌入式参考照，共 63 位模特。分类为“全部 / 女模 / 男模 / 儿童”，沿用原地区筛选、选择、上传和云端试穿请求。素材来源见 `handler/tryon_assets/children-provenance.json`，测试与待验收记录见 `docs/content/docs/progress/pending-test.mdx` 的「服装上身儿童模特」。

上述简化方案已随 v0.19.124（`c41445d`）发布生产，24 项儿童原图/缩略图均通过公网哈希核对。下方为先前调研与候选方案，细分年龄建议不属于当前实施范围；尚未执行真实收费童装试穿，实际成片质量仍待验收。

## 结论

当前缺少儿童模特，直接原因是沿用固定种子图库，尚未加入年龄分类及明确登记的儿童素材。不是发现了“试衣功能禁止儿童”的代码限制。

最适合参考的是 FASHN 的年龄筛选与云端试衣路线，其官方产品明确包含儿童、幼童图库分类，并声明支持童装。GitHub 中的试衣代码、API 示例与商业产品图库应分别看待，不能因为代码开放就认定儿童图库也可下载后用于本站。

本轮完成源码检查、线上公开图库只读核查及 GitHub/厂商一手资料调研，没有增加儿童素材、调整生成提示词、调用收费生成或发布生产。

## 适合当前项目的实施建议

1. 先补图库和筛选。年龄与地区、性别独立，建议界面增加“全部 / 成人 / 幼童 / 儿童 / 青少年”。婴儿单独评估，不能默认套用站立姿势。具体年龄范围和素材数量在准备素材时确定。
2. 首批准备本站可使用的儿童人物图，覆盖男童、女童及不同年龄感。素材至少记录人物标识、年龄组、性别、缩略图、原图和来源；优先自然站姿、完整身体、清楚五官及简洁背景。
3. 复用现有上传与云端多图编辑链路。人物图决定身份、年龄感及身体比例，童装图决定商品，不把成人照片缩小当作儿童模特。
4. 用童装上衣、裤装、连衣裙、套装和连体衣覆盖不同身体比例，先看原姿势，再验证侧身、迈步及场景。婴儿连体衣与学龄儿童服装分组检查。
5. 每张检查年龄感、头身与四肢比例、脸部身份、衣长/袖长/裤长、印花文字及手脚遮挡。试衣展示与尺码推荐分开，不能将生成效果当成实际合身测量。
6. 现有链路满足需求时，优先完成儿童图库；不足时再评估 FASHN 云端试衣。当前服务器没有 GPU，研究开源仓库不意味着新增自部署推理服务。

涉及位置主要为图库数据、`TryonModel` 类型、模特筛选与生成约束；继续沿用现有官方素材校验，不开放任意外链。来源元数据与人物素材一起维护，避免只增加一个没有图片的儿童筛选。
