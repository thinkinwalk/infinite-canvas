## 配置与日常操作

关系为：渠道 → 渠道模型接入 → 平台模型 → 功能步骤。

| 对象 | 管理内容 |
| --- | --- |
| 渠道 | 地址、密钥、协议、分组、启停和现有权重 |
| 渠道模型 | 稳定接入编号、真实模型 ID、固定版本、适配器、操作、素材及视频规格 |
| 平台模型 | 稳定模型编号、内部名、展示名、用途说明、允许接入、价格及启停 |
| 功能绑定 | 模块具体步骤允许的模型、接入子集、默认项、排序及清晰度/时长子集 |

新增模型时，先在渠道设置维护已接入的真实模型，再在模型管理中新增渠道模型并选择适配器；创建平台模型、设置展示和价格，最后绑定所需功能。新平台模型默认停用、不自动绑定功能。抽屉“应用到草稿”只修改页面草稿，点击“保存配置”并确认影响摘要后才写入。

平台模型可以仅显示别名、仅显示真实 ID，或同时显示两者。同名展示项在选模及插件目录中附加稳定平台编号以便区分，不暴露渠道真实身份。请求使用稳定平台编号，后端解析真实模型，适配器决定请求结构；改别名不改变计费身份或适配器。单个平台模型关联多个渠道时，必须使用相同真实模型、版本和适配器，前台采用共同可用规格；不同身份应分别创建平台模型。

后台提供平台模型、功能绑定、渠道模型三个视图，支持筛选、复制平台模型、批量停用、批量绑定/解绑，以及按模型或按功能编辑同一关系。全局保存前展示受影响步骤、默认项、接入和价格变化。已有平台/接入编号保留，通过停用退出；渠道真实身份不可原地替换，以免破坏历史恢复。

v0.19.94 列表收纳：点击“已绑定 N 项”打开功能抽屉，按模块查看或搜索；案例统一分组，分组勾选只作用于筛选后可见项，隐藏项保留。选择后“应用到草稿”，再全局保存；关闭未应用的选择时可继续编辑或放弃。点击“N 个接入”查看真实模型、适配器及有效启停状态；维护接入仍使用“渠道模型”视图。批量功能和允许渠道仅展示一个标签及剩余数量，避免撑高列表。

v0.19.94 分类入口：“全部 / 文字 / 图片 / 视频 / 音频”按接入能力自动归类，数量统计完整草稿中的平台模型，停用项也计入，同一模型多个接入不重复计算；无接入模型只在“全部”出现。切换管理视图保留分类；“适用模块”按已启用绑定和允许接入定位现有用途，功能绑定视图仍可为兼容的未绑定模型新增关系。筛选变化清除表格勾选并回到第一页，分类变化另清除批量功能；“重置筛选”保留配置草稿。渠道类型以中文展示，新接入按当前分类预填通用适配器与能力，保存仍遵守后端原有校验。

### 只取消 H3 的人物替换

在功能绑定中选择“内容替换 · 整个人物替换”，关闭 H3 的“允许使用”，必要时另选默认项，再保存。其他功能绑定独立保留。

首次“转换现有配置预览”已排除真实 ID 为 `h3-video` 的 `replace.person` 绑定，保留其他符合能力的用途。该规则只作用于显式转换草稿，并非永久禁止管理员手动重新绑定，也未自动修改当前数据库或生产环境。

转换不能代替管理员确认模型质量。对既有配置的能力/价格推断、零点价格、未定价、初始默认项及用途均需逐项检查；缺价模型保持停用，已有零点价格显式标记免费供核对。

## 配置、计费和历史保护

- 私有设置为权威配置，普通目录由后端派生，不包含渠道凭据。JSON/SSE 模型元数据使用稳定编号，错误中真实模型按展示策略处理；生成正文及媒体字节不做全局文字替换。
- 配置保存检查 ID、适配器/协议、功能操作、视频规格、正数价格或明确免费、多渠道一致性及唯一默认项。专用云模型固定版本须与已实现适配一致。
- 管理员保存带版本检查，过期编辑被拒绝；首次保存把原配置事务性备份到设置键 `model-management-original`。这是配置备份，不能代替部署前完整数据库及文件备份。
- 报价签名绑定账号、分组、功能、平台模型、原渠道、版本和计费参数。执行前重新校验；修改价格或绑定后旧报价失效。案例还绑定可信案例配置、版本、服务费及适用数量；套图按每张生成报价与执行，不把单张报价当成整套总价授权。
- 沿用既有用户分组、扣费、幂等与退款逻辑，不新增自动收费重试、并发、时长或媒体大小上限。
- 新生成受最新开关控制；已提交任务保存模型/展示名/渠道及必要计费快照，查询和退款沿用原身份。整片尚未提交的后续收费步骤重新校验绑定，配置变化时暂停确认。
- 前端保存通知、焦点恢复及页面可见性变化触发目录刷新。目录加载失败清除可执行平台配置；旧草稿失效模型/规格重新核对，不清空媒体或作品。
- 画布云端语音先报价确认、记录任务编号，再提交；中断后按编号恢复查询。明确失败/取消时允许用户另行发起；不确定状态保留编号，不自动再收费。音色按适配器展示，云语音不显示尚未支持的格式/语速/指令设置。
- 插件视频复用费用确认与绑定、插件目录使用配置展示名；插件生成接口缺少目标节点编号，刷新后的插件节点恢复仍由插件自己的状态实现，未承诺宿主自动保存每个插件节点的任务。

## 扩展边界
