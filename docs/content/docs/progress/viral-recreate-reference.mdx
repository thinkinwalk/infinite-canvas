# 爆款复刻优化方案

## 范围与结论

通过比特浏览器 CDP `63037`，在同一会话独立标签比较 `http://127.0.0.1:3000/video/viral-recreate` 与 `https://6688ai.quantv.com/video-recreation`，完成方案后按用户授权实施专用工作台。浏览器检查使用独立标签，流程验证使用隔离浏览器和模拟接口，没有创建真实收费任务。原标签与窗口保留。

## 实施状态

已接入 `viral-recreate-workspace.tsx`、`viral-recreate-request.ts` 和 hook/type 的复刻分支：独立滚动、可见底部操作、原视频与商品独立分析、人物用途说明、显式首帧、统一脚本/报价/生成规格、新稿建议与手稿保留、源视频派生缓存和采样时间、稳定引用、本浏览器作品和原任务恢复。

模型列表复用后台能力与刷新；视频参考仅在当前能力允许且用户显式启用时发送，不根据模型名称推断。Wan 复刻保持单首帧；人物/商品合成首帧、多镜头后期和独立配音字幕仍属后续扩展。浏览器流程证据见下方，真实效果、真实扣费退款与触摸/键盘等人工验收见 [Pending Tests](/docs/progress/pending-test)。后文保留设计依据和后续验收要求。

原对比结论是优先修复输入滚动与生成按钮可达性，并明确参考视频、商品、人物与生成首帧用途。当前已按该结论落地；流程仍是抽样画面/可选转写 → 文字模型分析 → 新脚本 → 短片生成，Wan 路线不直接把原视频送入视频模型，不应承诺逐镜头或动作精准复刻。

## 实页依据

### 对标页可借鉴的交互

- 桌面左侧输入独立滚动，模型、视频设置、预计费用与生成按钮常驻底部；右侧「作品示例 / 我的作品 / 教学示例」展示结果。
- 原视频上传区明确「参考结构与节奏」，AI 分析入口就近放置；空态解释适用带货、种草、产品展示、口播、氛围视频。
- 原视频分析与参考图片素材分析分开；商品参考图片和模特图片分区，模特注明「不参与素材分析」。本次新开页面显示模特 `1 / 1`，不能据此当作本站需要预置模特的依据。
- 补充说明支持 `@` 引用，生成脚本就近呈现；右侧原视频与复刻视频并排，便于比较开场、商品与构图。
- 本次默认显示 `16:9 / 4秒 / 720p`、预计 `3.20积分`；视频分析显示 `0.50积分`、图片分析 `0.10积分/张`、脚本 `0.10积分`。这些都是对标页面显示值，未验证实际扣费，不能复制为本站价格。
- 对标文案有「15秒以内」、图片 `0 / 6` 和补充说明 `0 / 5000`。本站沿用已确认的模型能力与现有上传规则，不复制这些限制，也不新增未经确认的边界。
- 看到原视频/复刻视频示例播放器；本轮没有验证其真实输入、生成效果、收费与教程播放链路。
- 参数菜单显示六种比例、4–15秒时长控件及 480p/720p；模型菜单展示 mini/fast/pro、2.5、视频编辑、H3、Wan 等名称。仅观察菜单，没有切换模型、测试参数兼容性或据此推断上游能力。「我的作品」本次读取时仍在加载，「教学示例」出现「复刻视频教学」，不能作为这些流程已验收的证据。

## 推荐页面与操作流程

保留本站顶栏、主题 token 和中文文案。桌面采用约 400–440px 输入栏与弹性结果栏，宽度可按实页调整；左栏独立滚动，底部操作固定在栏内。手机单栏滚动与可见底部操作，留出安全空间防止遮挡最后一行和键盘输入。

左栏顺序：

1. **参考视频**：拖放/选择文件/我的素材，显示播放器、文件名、已读取的时长与替换/移除。用途提示「参考结构、开场与表达节奏」。上传不自动创建收费分析任务。
2. **参考拆解**：抽样画面、可选转写、结构分析；抽样图显示时间，支持预览/定位原视频。分析文本可修订、放大、复制，标注「画面分析 / 已结合转写」以及输入变更状态。
3. **新商品**：商品图片独立上传与分析，用户填写名称、卖点、适用人群等真实资料；未知价格、优惠、功效不编造。允许手动提供资料，不强制运行 AI。
4. **出镜人物（可选）**：独立图片角色，用于外观参考；只有当前模型确实接收此图时标「视频参考」，否则标「首帧准备/分析辅助」。原视频人物是否保留不能仅靠上传新人物图承诺实现。
5. **改编要求与脚本**：说明保留的开场、节奏、镜头形式及希望修改的卖点/场景；`@` 引用稳定素材。AI 提供新稿建议，明确采用后替换，失败和迟到返回保留手工脚本。
6. **本次生成素材**：按当前模型展示实际发送的图/视频/音频；Wan 显示并要求确认唯一首帧。允许用户显式选择原视频抽样帧，但提醒其中仍包含原主体。首帧上传入口写「选择/上传生成首帧」，当前并没有生成图片调用，不能命名为已支持 AI 合成首帧。

底部：模型、实际规格、能力说明、查看本次费用、主生成按钮。高级处理服务与文字模型收进相关阶段设置，不占据主输入首屏。

右栏：

- **当前作品**：输入原视频与任务输出并排播放器，保留各自时间轴和音量；不是自动证明动作一致。窄屏上下排列。任务显示阶段进度、查询中断/可恢复、失败原因与重试入口；完成后下载、保存素材、加入画布。
- **本浏览器作品**：阶段记录/视频作品按任务展示时间、模型、规格、输入摘要与状态。查看结果不覆盖草稿，显式「恢复输入」才恢复快照。
- **使用说明**：说明结构借鉴与视频直接参考的差别、抽样误差、首帧用途和输出范围。无本站同工具真实样例时使用指导空态，不拿对标视频当本站效果。

## 分析与缓存：按真实来源组织

### 抽样画面

`video-worker/app.py` 当前在 `duration × index / count` 处抽帧，返回总时长与 fps；这不是关键帧检测。第一阶段保留现有均匀采样策略，不新增抽帧数量上限。记录源视频 id、采样数量、时长和每帧采样时间，标签使用采样时间，不能当作 FFmpeg 解码后的逐帧时间码。镜头检测和精确边界识别后续独立扩展。

源视频替换/移除使对应画面、转写与视频结构分析失效；修改采样数只使画面/结构分析待更新，不清空语音原文。新增商品/人物图不重新抽帧、不重新转写。输入变化保留旧稿并标注来源过期，禁止直接把旧分析作为新输入已完成结果。

### 转写与结构分析

- 抽帧检查 `frames` 能力，转写检查 `transcribe`；Whisper 不可用时允许粘贴转写或跳过，按画面分析。用户手写脚本且已有合规首帧时不需要 worker。
- 结构分析只接收原视频抽样画面和可选转写，给出开场、可见镜头顺序、表达方式、卖点承接与结尾。无音轨文本时明确画面依据，不推断原口播、音乐节拍或准确转场时刻。
- 商品分析接收新商品图和用户资料，人物图按用途单独处理；保留本站已有「不虚构价格/门店信息/促销」约束，并覆盖功效与承诺。
- 可编辑文本先落地，不强行引入分镜 JSON、自动解析或复杂 DAG。完整分镜表属于进一步能力建设，不能用格式包装模拟已完成镜头检测。
- 每阶段按输入快照执行，返回时核对版本；更新建议不得覆盖用户新输入。失败保留之前成功阶段，重试只执行选定阶段，不自动重复整套分析和收费。

## 生成路线与真实输入

| 路线 | 原视频用途 | 新商品/人物用途 | 允许呈现的结果范围 |
| --- | --- | --- | --- |
| 当前 Wan 2.2 单首帧路线 | 仅抽样/转写/文字结构分析；不送入视频模型 | 参与分析与新脚本；要进入画面，需已包含新主体的显式首帧 | 约 5 / 7.5秒、480p / 720p 的单片段；比例跟随首帧，不承诺多镜头复刻 |
| 后台已确认多图的参考模型 | 若 `maxVideos=0`，仍只用于分析 | 按能力传送所选商品/人物图及正确引用 | 按已确认时长/比例/清晰度生成短片；多图参考不等于精确商品、人物与动作一致 |
| 后续已确认支持原视频的通道 | 能力明确允许时才传原视频 | 仅在同时支持对应图片输入时发送 | 须真实素材验收结构/动作保留；不能凭 Seedance 名称推断视频或音频参考能力 |

复用普通 `/video` 的后台启用模型目录、能力 profile 与刷新逻辑。已打开标签也能更新停用状态与规格；更换模型保留草稿，对不受支持的素材给出具体解释，不能悄悄丢弃。

Wan 不默认取 `frames[0]`。要把新商品或人物加入原画面，需要用户上传已准备首帧，或后续接入图像生成/主体合成步骤；新增图像生成有独立费用与真实效果验收，第一阶段不自动串联。音频未确认支持时不展示原生配音承诺；脚本中的口播、字幕、配乐建议并不表示成片已经包含这些内容。

当前目标是「用参考表达改编新的短片」。分镜分段生成、片段筛选、剪辑、字幕配音和完整成片合成留待后续；如果用户要精确替换原人物/商品，可在说明中链接已有内容替换工具，不混淆两种任务。

## 规格、收费和恢复

- 为复刻复用/增加统一请求构造，脚本目标时长、报价字段、实际提交均读取同一规格与本次素材快照。
- Wan 用现有 `quoteReplicate` 与确认流程；已确认普通视频通道用 `quoteVideoModel`。不得从对标价格推导本站价格；无法报价时显示具体原因，不编造预计积分。
- 分开标注原视频分析、商品分析、文案与视频费用来源。自定义文字模型按用户渠道计费，不写成本站固定积分；视频报价不代表整个流程总费用。
- 素材/脚本/模型/规格/登录变化使旧视频报价失效；迟到异步响应不能覆盖新报价。正式提交重新报价确认，取消确认不创建失败作品或收费任务。
- 本次视频记录保存原视频与素材引用、分析/转写/脚本、选定首帧、能力/规格及原提交模型/渠道标识。敏感密钥仍使用现有配置，不为作品快照额外复制凭据。
- 恢复查询沿用原任务路由与配置，不使用当前新模型；原凭据缺失时提示恢复所需配置，不重新提交任务。停止等待、上游取消与恢复查询使用真实语义，只在已有渠道支持时提供上游取消。
- Zustand/localforage 保存草稿和记录，仍是本浏览器数据；不标作云同步。阻止重复提交可恢复任务，复用现有任务控制，不静默新增轮询/超时/重试或文件保存边界。

## 实施顺序与文件范围

### 第一阶段：可用性与真实输入（P0）

1. 新建 `web/src/pages/video-tool/viral-recreate-workspace.tsx`，`index.tsx` 只对该工具分派专用页；复用已完成探店/内容替换的高度、滚动、固定操作与主题实现。
2. 参考视频前置，商品与人物独立；生成输入可见，Wan 显式确认首帧，清楚显示缺失条件与单片段范围。
3. 为复刻增加最小必要类型和请求工具，统一脚本/报价/提交规格；复用现有服务，不复制整个普通视频页。

### 第二阶段：分析、手稿和任务（P1）

1. 在 `use-video-workbench.ts` 的复刻分支隔离参考结构/商品分析；原视频派生结果绑定源，时间戳沿用现有采样公式，worker 能力按阶段检查。
2. `types/video-workbench.ts`、`use-video-workbench-store.ts` 增加需要的素材角色、来源/待更新状态、新稿建议与复刻输入/提交快照；采用稳定 id 和已有 mention helpers。
3. 真实报价、旧报价失效、模型刷新与后台能力校验；当前作品、原视频对照和历史恢复。

### 后续扩展（P2）

先用真实输入验收当前改编效果，再决定合成首帧、视频直接参考通道、镜头检测、多片段生成与合成、独立配音字幕。官方对照必须来自本站本工具真实处理同一输入，包含模型与实际规格。

## 验收要求

- **布局**：1920×953、1440×900、1366×768、390×844 全部输入可达、生成按钮可见、无横向溢出；浅/深色、触摸、键盘弹起、Agent 面板与放大编辑不遮挡操作。
- **来源与缓存**：替换视频使旧画面/转写失效；增加商品图不重复抽帧；改采样数不丢转写；旧分析明显待更新；迟到返回不覆盖新视频或手稿。
- **能力**：无 worker 能手写脚本+合规素材生成；无 Whisper 可跳过/粘贴转写；抽样时间有来源；无音轨不编造声音；不支持视频参考时原视频不发送。
- **请求**：Wan 只传明确选择的首帧，不偷取原视频第一帧；多图角色/顺序/引用正确；实际请求、报价与脚本时长一致；停用模型和规格变化即时生效。
- **费用与任务**：取消确认不创建收费预测；恢复原任务只查询；重复点击不重复收费；原任务配置缺失可解释；停止等待不误称取消成功。
- **结果**：查看历史不覆盖草稿；原视频/输出播放、下载、保存素材、加入画布可用；改变输入后不会把旧成片误标成新作品。
- **真实效果**：同一原视频+新商品+可选人物素材，核对开场/表达节奏、商品外观与文案、人物、动作、字幕/声音的真实输出范围。模拟流程只能证明交互和请求，不能作为效果或扣费退款验收。
- **回归**：内容替换与探店已完成工作台保持正常；公共 hook 的调整仅在复刻分支生效，其他工具独立核验。
