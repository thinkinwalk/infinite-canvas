# 视频链接导入

当前实现第一阶段：视频号分享链接导入。视频创作台（模型支持视频参考时）、内容替换、探店、爆款复刻、数字人视频学习与视频素材、视频对口型、视频高清、硬字幕去除的素材输入区增加链接提取。抖音、小红书链接可以识别来源，但会明确提示尚未接入，继续使用本地上传。

## 操作与数据

登录后粘贴 `https://weixin.qq.com/sph/...` 分享链接，或含单条链接的分享文案，点击「提取视频」。普通 `channels.weixin.qq.com` 页面地址不按无桌面依赖的链接处理，需要重新复制 SPH 分享链接。

应用后端请求解析服务，下载并核验 MP4 和时长，再返回浏览器。浏览器检查可播放性；编码不兼容时使用已有视频处理服务转换。成功后替换对应工作台位置的素材，视频创作台则追加视频参考，显示来源作者与标题，后续流程沿用本地上传逻辑。提取不自动提交分析或收费生成任务。

素材文件保存在当前浏览器的 localforage，各专用工作台在草稿中保留来源信息。视频创作台沿用既有生成历史保存参考素材与来源，不新增刷新前未生成输入的草稿恢复机制。导入成功不删除原素材存储文件；取消、解析失败、素材变化或登录切换时不覆盖当前素材。应用服务器仅使用请求期间的临时文件，成功和失败后均清理。

## 管理员配置

配置运行 Go 应用的环境变量，并重启后端：

```dotenv
VIDEO_IMPORT_WX_ENDPOINT=https://your-authorized-parser.example/api/fetch_video_profile
VIDEO_IMPORT_WX_TOKEN=your-parser-access-token
```

仅支持以下明确的接口协议：

| 接口路径 | 请求 | 响应 |
| --- | --- | --- |
| `/api/fetch_video_profile` | POST，JSON `{"url":"分享链接"}` | `{"errCode":0,"data":{"feedInfo":{...},"authorInfo":{...}}}` |
| `/api/channels/parse_sph` | GET，查询参数 `url=分享链接` | `{"code":0,"data":{"errCode":0,"data":{"feedInfo":{...},"authorInfo":{...}}}}` |

`feedInfo` 需要返回 `h264VideoInfo.videoUrl`、`videoUrl` 或 `h265VideoInfo.videoUrl`，依次优先使用；标题读取 `description`，作者读取 `authorInfo.nickname`。应用向解析接口发送 `Authorization: Bearer VIDEO_IMPORT_WX_TOKEN`；服务不需要访问令牌时可留空。应使用自己控制且有权使用的 HTTPS 服务；不要在地址中放置用户信息或查询凭证，凭证请求不跟随重定向。

解析服务部署、登录及上游 Cookie 刷新由管理员在该服务侧维护。微信或元宝 Cookie 不放在本项目页面和前端配置中。未配置接口时功能返回明确提示，不会自动调用公开免费解析站。

## 开源项目评估

- [Evil0ctal/Douyin_TikTok_Download_API](https://github.com/Evil0ctal/Douyin_TikTok_Download_API)：较完整的自托管 REST API，提供 Docker Compose、身份池、任务调度及管理界面；其开源自托管平台矩阵为抖音、TikTok、B 站。README 另外宣传含小红书的专业数据产品，那不是此仓库内的自托管适配器；项目未列出视频号。Apache-2.0 允许商用，但部署依赖 PostgreSQL/TimescaleDB、Redis 和多个容器；接口默认异步并归档解析内容，与本应用当前同步返回短时腾讯 CDN 媒体地址的契约不同，不能直接接上。可作为后续抖音适配候选，需单独设计任务轮询、媒体代理与保留策略，并评估运行成本及平台条款。
- [ltaoo/wx_channels_download](https://github.com/ltaoo/wx_channels_download)：可参考视频号服务端解析接口，但其许可包含 Commons Clause，限制以收费方式提供主要价值来自该软件的产品或服务；商用前需取得单独许可。当前应用未复制或捆绑其实现。

因此，当前架构只接入管理员自行配置、具有合法使用权的解析 API；不依赖公共演示站，不在应用内启动桌面微信，也不把解析任务交给用户电脑。后续接入抖音或小红书时，需各自确认服务 API、身份要求、许可和平台可用性，再实现独立适配器。

## 边界与安全

- 视频下载复用现有参考视频的 50 MiB 限制，超限提示失败，原素材保留。解析响应与请求体复用现有参考媒体的 80 MiB 上限。
- 解析、下载及服务器媒体检查合用现有 15 分钟 AI 请求超时；超时终止请求。浏览器兼容转换沿用现有处理服务机制。
- 远程解析服务只允许 HTTPS；HTTP 仅允许 loopback 本机服务。解析请求不跟随重定向。
- 下载只接受腾讯 `*.qq.com`、`*.qpic.cn` 媒体地址；重定向继续检查域名，保留 HTTP 标准最多 10 次重定向规则。拒绝用户信息、显式端口、片段地址和私有/环回/链路本地/共享地址，解析后直接拨号至已校验 IP，禁用下载代理。
- 后端要求可执行的 FFprobe，复用 `FFPROBE_PATH` 配置；容器或服务器需要保证该程序可用。仅凭扩展名或上游 Content-Type 不认为文件有效。
- 无法保证已删除、私密、登录受限、图文或平台规则变更后的链接可提取；本次未接入任何付费第三方解析套餐。

## 待验收

需要管理员配置真实的已授权解析服务，并使用可访问的视频号 SPH 链接验证：解析成功率、登录续期、实际 CDN 地址、视频预览、刷新后的素材与来源保留、兼容转换、取消和失败后的原素材保留。当前自动化使用模拟解析响应和独立浏览器数据，不能替代真实服务联调。
