# 视频链接导入

视频创作台（模型支持视频参考时）、内容替换、探店、爆款复刻、数字人视频学习与视频素材、视频对口型、视频高清、硬字幕去除的素材输入区支持粘贴分享链接提取。抖音、小红书、快手、微博、B站、西瓜视频、皮皮虾、AcFun、YouTube、X、TikTok、Instagram 等由第三方服务明确列出的平台均可尝试；服务另称支持 30 多个平台，其他公开网站也会交由其 yt-dlp 适配器尝试。视频号仍走单独配置的解析服务，不能由此推定第三方服务支持视频号。单个平台是否成功取决于分享权限、上游可用性及服务端支持状态。

## 操作与数据

登录后粘贴单条视频分享链接或含单条链接的分享文案，点击「提取视频」。普通 `channels.weixin.qq.com` 页面地址不按视频号 SPH 链接处理，需要重新复制 `https://weixin.qq.com/sph/...` 分享链接。

应用后端请求解析服务，下载并核验 MP4 和时长，再返回浏览器。浏览器检查可播放性；编码不兼容时使用已有视频处理服务转换。成功后替换对应工作台位置的素材，视频创作台则追加视频参考，显示来源作者与标题，后续流程沿用本地上传逻辑。提取不自动提交分析或收费生成任务。

素材文件保存在当前浏览器的 localforage，各专用工作台在草稿中保留来源信息。视频创作台沿用既有生成历史保存参考素材与来源，不新增刷新前未生成输入的草稿恢复机制。取消、解析失败、素材变化或登录切换时不覆盖当前素材。应用服务器下载链接时仅使用请求期间的临时文件，成功和失败后均清理；后续模型上传及 Worker 副本另按下方保留策略管理。

## 原片、分析与保留

原片导入上限调整为 300 MiB（界面显示 300MB）。抽帧与 Worker 转写使用单独的 720p 分析副本，保持比例、音轨和时间轴；竖屏为最高 720×1280，小视频不放大。重复分析复用同素材缓存，裁剪后重新准备。原片与兼容播放副本分别保存，内容替换和裁剪不使用低分辨率分析副本。平台模型上传仍遵守既有 50 MiB 预算，大文件先在应用端生成模型参考副本，失败时提示选择较短片段。

只有本轮开始新导入并登记的参考/学习视频进入临时管理。默认闲置 7 天后可清理；已有生成结果时点击「完成对比」，改为 24 小时后可清理；再次用于处理会恢复闲置计时。「保留素材」排除自动清理，关闭后从当前时间重新计算闲置期限。历史素材、数字人形象、任务记录和生成作品不追溯删除。

到期是可清理时间，实际扫描会因活动任务、共享引用或服务异常顺延。浏览器须应用打开且支持 Web Locks，在启动、获得焦点和每小时扫描；保护已保存到素材库、画布、预设及运行/中断任务的本地文件。服务端独立每小时清理显式登记的模型参考和 Worker 输入、兼容/分析/裁剪副本，活动或未知任务阻止删除。清理只移除媒体数据，保留来源与分析文字，历史成片仍可单独打开和下载。浏览器关闭时不会执行本地清理，后台服务器继续按任务状态检查。

除视频号外，分享链接会发送给配置的第三方解析服务。本项目默认使用 `https://ynvan.com/api/parse`；该服务运营方声明不会保存粘贴链接和下载文件，但其服务受单 IP 调用频率限制。不要粘贴私密、带登录凭证或无权处理的链接。

## 管理员配置

配置运行 Go 应用的环境变量，并重启后端：

```dotenv
VIDEO_IMPORT_WX_ENDPOINT=https://your-authorized-parser.example/api/fetch_video_profile
VIDEO_IMPORT_WX_TOKEN=your-parser-access-token
VIDEO_IMPORT_ENDPOINT=https://ynvan.com/api/parse
```

`VIDEO_IMPORT_ENDPOINT` 可选，用于替换其他具备兼容 API 的解析端点；未设置时使用上方默认地址。服务调用格式为 `GET /api/parse?url=分享链接`，读取 `data.video_url`（缺失时回退到 `data.formats[].url`）、`data.title`、`data.author.name` 与 `data.cover_url`。来源平台按分享链接域名识别；未知站点标记为“其他平台”。

仅支持以下明确的接口协议：

| 接口路径 | 请求 | 响应 |
| --- | --- | --- |
| `/api/v1/parse` | POST，JSON `{"url":"分享链接"}` | Media-Parser 标准响应，`data.video_url`、`data.title`、`data.author.nickname`、`data.cover_url` |
| `/api/fetch_video_profile` | POST，JSON `{"url":"分享链接"}` | `{"errCode":0,"data":{"feedInfo":{...},"authorInfo":{...}}}` |
| `/api/channels/parse_sph` | GET，查询参数 `url=分享链接` | `{"code":0,"data":{"errCode":0,"data":{"feedInfo":{...},"authorInfo":{...}}}}` |

`feedInfo` 需要返回 `h264VideoInfo.videoUrl`、`videoUrl` 或 `h265VideoInfo.videoUrl`，依次优先使用；标题读取 `description`，作者读取 `authorInfo.nickname`。应用向解析接口发送 `Authorization: Bearer VIDEO_IMPORT_WX_TOKEN`；服务不需要访问令牌时可留空。应使用自己控制且有权使用的 HTTPS 服务；不要在地址中放置用户信息或查询凭证，凭证请求不跟随重定向。

可将管理员自建的 Media-Parser API-only 服务配置为 `/api/v1/parse` endpoint。该项目的视频号解析说明指出，完整视频流可能需要有效的腾讯元宝 Cookie；匿名解析不保证返回媒体直链。解析服务部署、登录及上游 Cookie 刷新由管理员在该服务侧维护。微信或元宝 Cookie 不放在本项目页面和前端配置中。未配置接口时功能返回明确提示，不会自动调用公开免费解析站。

## 开源项目评估

- [Evil0ctal/Douyin_TikTok_Download_API](https://github.com/Evil0ctal/Douyin_TikTok_Download_API)：较完整的自托管 REST API，提供 Docker Compose、身份池、任务调度及管理界面；其开源自托管平台矩阵为抖音、TikTok、B 站。README 另外宣传含小红书的专业数据产品，那不是此仓库内的自托管适配器；项目未列出视频号。Apache-2.0 允许商用，但部署依赖 PostgreSQL/TimescaleDB、Redis 和多个容器；接口默认异步并归档解析内容，与本应用当前同步返回短时腾讯 CDN 媒体地址的契约不同，不能直接接上。可作为后续抖音适配候选，需单独设计任务轮询、媒体代理与保留策略，并评估运行成本及平台条款。
- [ltaoo/wx_channels_download](https://github.com/ltaoo/wx_channels_download)：可参考视频号服务端解析接口，但其许可包含 Commons Clause，限制以收费方式提供主要价值来自该软件的产品或服务；商用前需取得单独许可。当前应用未复制或捆绑其实现。

视频号继续使用管理员自行配置的解析 API，不在应用内启动桌面微信，也不把解析任务交给用户电脑。其他平台使用兼容解析 API，用户分享链接会发送到该外部服务；可用性、频率限制及其隐私声明由服务运营方控制。

## 边界与安全

- 原片下载及本地参考视频导入允许最多 300 MiB，超限提示实际体积或流式下载超限，当前素材保留；平台模型参考文件维持 50 MiB 预算并单独转换。链接解析响应与请求体复用现有参考媒体的 80 MiB 上限。
- 解析、下载及服务器媒体检查合用现有 15 分钟 AI 请求超时；超时终止请求。浏览器兼容转换沿用现有处理服务机制。
- 远程解析服务只允许 HTTPS；HTTP 仅允许 loopback 本机服务。解析请求不跟随重定向。
- 视频号下载只接受腾讯 `*.qq.com`、`*.qpic.cn` 媒体地址；其他平台仅接受带公网主机名或公网 IP 的 HTTP(S) 媒体地址。重定向继续执行相同校验，保留 HTTP 标准最多 10 次重定向规则。拒绝用户信息、显式端口、片段地址和私有/环回/链路本地/共享地址，解析后直接拨号至已校验 IP，禁用下载代理。
- 后端要求可执行的 FFprobe，复用 `FFPROBE_PATH` 配置；容器或服务器需要保证该程序可用。仅凭扩展名或上游 Content-Type 不认为文件有效。
- 无法保证已删除、私密、登录受限、图文或平台规则变更后的链接可提取；本次未接入任何付费第三方解析套餐。

## 接入变更与待验收

应用后端已接入兼容 `GET /api/parse?url=...` 的第三方解析 API，同时保留视频号 Media-Parser `/api/v1/parse` 等原有接口。自动化使用模拟解析响应；真实抖音链接已验证第三方接口返回视频地址和元数据，但完整媒体下载、FFprobe 与浏览器解码仍待验收。小红书和其他平台还需使用有效公开链接逐平台实测。第三方服务不支持视频号时，视频号功能仍依赖自有解析配置和有效凭证。

需要管理员配置真实的已授权解析服务，并使用可访问的视频号 SPH 链接验证：解析成功率、登录续期、实际 CDN 地址、视频预览、刷新后的素材与来源保留、兼容转换、取消和失败后的原素材保留。当前自动化使用模拟解析响应和独立浏览器数据，不能替代真实服务联调。

多平台链接解析接入已随 v0.19.78 发布；300MB 原片导入、分析副本和保留策略已随 v0.19.79 同步部署 Go 应用、前端静态资源与 Worker，内外健康、能力接口、清理预检与发布资源核对通过。验收仍需覆盖抖音、小红书、快手、B站及至少一种海外平台的真实链接，并检查失效链接、解析限流、真实 CDN 下载、大视频上传、MP4/FFprobe、浏览器预览、取消、原片保留及过期后的成片访问。
