# 视频内容替换优化方案

建议将 `/video/content-replace` 调整为专用工作台：先选替换对象，再上传素材，左侧完成设置，右侧查看结果与历史。第一步必须修复页面无法滚动的问题，否则底部的替换模式和生成按钮无法通过普通滚轮操作到达。

## 实施状态

- 已落地专用双栏、滚动与常驻操作区、模式对应素材与参数、费用预估与确认、原片/成片对照、本浏览器作品与任务输入恢复。具体待验收项目见 [Pending Tests](/docs/progress/pending-test)。
- 比特浏览器四种尺寸的页面检查通过；独立浏览器使用测试素材与模拟接口检查报价、取消、字段联动、历史与刷新恢复。尚未提交真实付费生成，官方效果示例仍需真实业务素材验收。
- 默认分辨率、计价、上传大小及任务超时等既有边界保持；没有照搬对标的 15 秒、1080p 或积分数值。

## 核查依据

- 经比特浏览器本地 CDP 端口连接，确认已有本地页面与 `https://6688ai.quantv.com/content-replace`。
- 两页原始截图均为 1920×953。本地另用独立测试标签页检查 1440×900 与 390×844，使用鼠标滚轮复现裁切；对标另用独立标签页展开视频设置。页面核查没有对原标签执行关闭操作。
- 本地当前未登录，所以“登录后使用后台已配置的 Replicate”是登录状态提示，不能据此判断后台模型没有配置。
- 核对 `web/src/pages/video-tool/index.tsx`、`use-video-workbench.ts`、`use-video-workbench-store.ts`、`use-replicate-confirmation.tsx` 与服务端模型快照。
- 本轮没有上传业务素材、提交收费任务或验证成片质量；以下效果能力判断来自当前适配代码与既有待测试记录。

## 实页对照

| 项目 | 本地现状 | 对标实页 | 推荐调整 |
| --- | --- | --- | --- |
| 滚动 | 外层高度固定且 `overflow-hidden`，业务页面没有自己的滚动容器 | 左侧素材栏独立滚动 | 专用页面占满可用高度，提供明确的滚动区与常驻提交区 |
| 首屏 | 先展示高级设置、模型信息和分辨率，之后才是素材 | 素材位于输入栏主体，作品占主要空间 | 素材优先；模型名称和参数收为摘要，高级设置折叠 |
| 布局 | 1920 宽度下内容约 1232px，输入约 713px、结果约 499px | 输入区约 460px，右侧作品区约 1152px | 保留本站顶部导航；工作区展开，左栏建议 360–420px，右栏自适应 |
| 上传 | 小按钮，无可见拖拽区、格式引导与空槽预览 | 大面积拖拽区，文件选择与资产库双入口 | 原视频与当前模式参考图使用紧凑拖拽槽，显示名称、缩略图与媒体信息 |
| 模式 | 人物/商品/背景下拉位于所有素材之后 | 换模特/换产品分段按钮 | 模式放到最前，采用人物/商品/背景三个分段选项 |
| 字段 | 人物模式也出现背景图和通用商品营销描述框 | 始终展示模特/产品图与可选背景图 | 按本站实际调用动态显示必需字段；不展示当前请求不会使用的输入 |
| 结果 | 右侧仅约 197px 高的空态卡片 | 四个可播放作品示例，另有我的作品、教学示例 | 右侧作为主要结果区，支持原片/成片对照、本浏览器作品与使用说明 |
| 提交 | 未登录、无素材时“开始替换”仍可点击，点击后才报错 | 空输入时生成按钮禁用，附近显示预估积分 | 显示登录入口、缺失条件、参数摘要和报价；保留正式费用确认 |

对标页的生成按钮也位于左栏滚动区域底部，本方案建议进一步将提交区固定在输入栏底部，移动端则放到可见底部并预留内容空间。

## P0：恢复正常操作

1440×900 实测：业务父容器可视高度 844px、内容高度 1115px，计算样式 `overflow-y: hidden`；滚轮向下 1100px 后该容器 `scrollTop` 仍为 0。按钮位置为 `y=1102`，超出视口。390×844 下同一容器可视高度 788px、内容高度 1440px，问题更明显。

原因位于 `web/src/layouts/user-layout.tsx` 的固定高度布局与 `web/src/pages/video-tool/index.tsx` 的普通 `main` 组合。优先给内容替换专用页面正确的 `h-full/min-h-0` 布局和 `overflow-y-auto`，避免直接修改公共布局使画布或其他工具滚动方式改变。

桌面采用“可滚动输入区 + 常驻提交区 + 独立结果区”；窄屏采用单列滚动，预览仍可到达，底部操作区不遮挡最后一项输入。滚轮、触摸、键盘均能访问所有字段。

## P1：按真实能力重排输入

推荐顺序：替换对象 → 原视频 → 当前模式参考图 → 替换要求（有实际作用时） → 参数摘要 → 高级设置。顶部保留返回与任务入口，处理服务与模型设置进入高级设置。

| 模式 | 当前实际发送 | 主界面字段 | 参数与说明 |
| --- | --- | --- | --- |
| 人物 | Wan Animate：`video`、`character_image`、`resolution`、`merge_audio: true` | 原视频 + 单张人物参考图 | 480p/720p，默认保留现有 480p；原音轨合并。当前不发送文字要求或背景图，应隐藏这两个字段 |
| 商品 | Wan VideoEdit：`video`、`reference_image`、文字 `prompt` | 原视频 + 单张商品参考图 + 必填替换要求 | 当前使用 720p、原音轨；已有原视频要求为 2–10 秒。商品外观一致性仍需真实样片验收 |
| 背景 | Wan VideoEdit：`video`、`reference_image`、文字 `prompt` | 原视频 + 单张背景参考图 + 必填替换要求 | 当前使用 720p、原音轨；不额外展示人物/商品图片槽 |
| 掩膜编辑 | VACE：`src_video`、`src_mask`、`src_ref_images`、`prompt` | 在高级设置中按可用状态显示掩膜输入 | 既有记录显示尚未启用，运行时以后台可用状态为准；不可用时说明原因并阻止提交 |

重要的代码与界面不一致：

- 人物模式下，当前填写的 `instructions` 与上传的 `background` 不参与平台云请求，容易让用户误以为已生效。
- 替换图上传控件当前允许多选，但平台云路径只通过 `find(...)` 使用第一张。建议此功能的参考图明确单张替换语义，避免额外图片上传后被忽略。
- 商品模式当前的“说明商品、目标人群和想要的效果”过于泛化，改成具体编辑要求，例如“把手中的白色杯子替换成参考图中的蓝色杯子，保留人物动作和镜头”。
- 当前每次进入页面都检查 worker，本地测试得到 `127.0.0.1:8767/health` 连接拒绝。平台云人物替换不依赖该检查，应按所选渠道或需要后期处理时再检查，避免无关失败与能力标签干扰。

模式切换应保留已上传素材和文字，不自动生成、不清空历史；界面只展示当前模式字段，请求只取对应角色素材，相关结果失效沿用现有 hook 的规则。未启用模型的模式仍可查看说明，但必须明确不可提交的原因。

### 上传与参数

使用 Ant Design `Upload.Dragger` 或项目已有上传风格，实现整槽点击、拖放和“从我的素材选择”。上传后展示视频封面/播放、图片缩略图、名称与时长；支持替换和移除，上传失败保留原素材并在槽位显示原因。上传中的状态也参与提交可用性判断。

格式、大小、时长说明以本站上传接口和实际模型能力为准。对标的 15 秒、视频 50M、图片 10M、1080p 与 4–15 秒选项不能直接照搬：人物模型当前仅 480/720，商品/背景已有 2–10 秒要求；其余边界应先核对并另行确认。此次方案不新增限制、不修改默认清晰度与价格。

人物模式的视频设置显示可选分辨率和当前音轨行为；商品/背景先如实显示“720p · 原音轨 · 输出时长跟随原片”。扩展 1080p、画面比例或裁剪时长属于后续能力和计价变更，需另做适配与验收，不能只添加看似可选但不会传出的控件。

### 提交与计费

- 未登录时显示“登录后开始替换”，支持进入现有登录入口；不要把“需登录”统一表达为模型停用。
- 无原视频、无当前参考图、缺少必填编辑要求、上传中或模型不可用时阻止提交，旁边直接显示缺失条件。参数缺失不应先创建失败记录。
- 上传完毕后可复用现有服务端上传与报价流程获取本次费用，提交区显示“预计消耗 N 算力点”；没有有效报价时显示“准备素材后计算费用”，不编造固定价。
- 预估失效跟随素材、模式和规格变化，异步返回只能更新对应的当前输入。正式提交仍重新核对报价并使用现有确认弹窗，保留 HTTPS 可达性、归属与最终费用校验。
- 不每次输入文字都重新上传素材；是否需要缓存上传引用应按现有引用归属与有效性实现，不自行引入新的保留时间。
- 运行时将输入区替换为进度摘要，保留“停止等待”和“取消任务”的区别；恢复查询不重复创建收费任务。

## P2：让结果区承担主要工作

- “当前结果”：上传原片后立即可预览；生成完成后支持原片与成片并排或切换对照，保留下载、保存素材、加入画布。视频保持原比例，不拉伸；必要时使用适合竖视频的展示高度。
- “本浏览器作品”：从现有 records 过滤本工具，显示缩略图、模式、状态与时间，支持恢复查询、查看结果。明确本地存储范围，不称为跨浏览器云作品。
- “使用说明”：按人物/商品/背景显示素材要求和常见失败原因。空态先使用流程引导；官方效果示例仅使用本站同一输入真实运行并验收的原片/参考图/结果组合，标注模型与规格。
- 输入改变后如果旧结果失效，历史仍可查看。是否显示上一结果需明确所属输入，避免把旧片误当作当前生成结果。
- 错误与任务状态在结果区持续显示，避免只依赖一闪而过的 toast；编码无法预览时保留下载与现有提示。

## 实施范围与顺序

1. 修复内容替换页面滚动与底部按钮可达性，检查窄屏布局。
2. 为内容替换新增同目录专用业务页面，例如 `web/src/pages/video-tool/content-replace-workspace.tsx`；原页面入口负责分派，继续复用 `useVideoWorkbench("content-replace")`、现有 store、素材选择器和云任务确认流程。
3. 完成模式前置、单张参考图槽、按能力显示字段、状态与提交条件；减少通用工作台首屏卡片。
4. 完成宽幅结果区、工具历史与使用说明，再将真实验收样片接入空态。
5. 将已实施项目从 TODO 移至 Pending Tests，并根据实际用户可感知变更追加 CHANGELOG；用户确认真实测试后再更新正式功能说明。

仅在实际需要时抽同目录上传/结果小组件；不重构其他视频工具、公共导航、后台定价或现有任务协议。页面样式使用 Ant Design token 与现有主题，不增加整页硬编码暗色或大量全局 CSS。

## 验收清单

- 1920×953、1440×900、1366×768、390×844 下，所有字段和主操作可访问；底部操作区不覆盖内容，鼠标滚轮、触摸与键盘均正常。
- 人物仅原视频和人物图必填，只有实际传出的参数可编辑；商品/背景必填要求符合请求，页面字段与请求角色对应。
- 点击选择文件、拖放、素材库选择行为一致；单张图替换不丢失其他角色素材；上传中、失败、移除后提交条件及时变化。
- 当前模式不可用、未登录和缺少素材的提示能区分；读取中不短暂误报“模型不可用”。
- 人物报价按当前分辨率与可信时长计算；商品/背景显示实际 720p 和原音轨；不复制对标积分或虚构时长支持。
- 报价取消不创建任务；重复点击、刷新与恢复查询不重复扣费；已有 HTTPS 拦截仍生效。
- 进行中、完成、失败、查询中断的结果区反馈可见；旧结果与历史身份明确，下载/保存素材/加入画布沿用原有链路。
- 浅色/深色、横竖视频、长文件名、Agent 面板展开时均无裁切；官方示例有真实本站处理依据。

本轮证据保存在仓库旁 `artifacts/content-replace-review/`：原始页面截图与 DOM 信息、桌面/移动截图、滚轮前后容器尺寸、对标设置截图和检查脚本。导航耗时来自本地开发与远端不同环境，不能用于得出正式性能优劣结论。

页面核查完成后的草图验证阶段，比特浏览器 CDP 连接中断，原因未确认。草图改用独立无头浏览器验证：人物/商品/背景字段联动、作品区标签切换通过，1024px 与 390px 宽度无水平溢出、无脚本异常。这是方案草图检查，不代表业务页面已修复。
