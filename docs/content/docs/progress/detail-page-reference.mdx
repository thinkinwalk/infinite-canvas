# 详情页工作台参考与策略

详情页入口位于 AI 商品套图与图裂变之间，使用独立页面。复用既有模型调用、报价和扣费接口，独立实现平台编排与浏览器排版导出。

## 开源参考

| 项目 | 采用的思路 | 本项目落地 |
| --- | --- | --- |
| [ecommerce-detail-page-generator](https://github.com/Gayaya999/ecommerce-detail-page-generator)（MIT） | 平台策略、无字底图与准确排字、实拍分流、交付清单 | 平台决定模块、宽度和上传包类型；文字用 Canvas 独立排版；实拍策略前后端阻止图片生成；ZIP 附带文案与尺寸清单 |
| [EcomGen](https://github.com/linbei0/EcomGen)（MIT） | 可编辑分镜、平台与市场分离、明确的导出完成状态 | 模块标题/正文/画面说明分开编辑，支持排序与启停；市场和语言独立；实际图片打包成功后才提示导出成功 |

参考架构与交互思路，未引入上游 Python、Worker 或整套后端。用户提供的 Etsy PDF 作为实物商品保守策略参考，文档里的绝对表述不作为所有 Etsy 类目的官方政策结论。

## 平台制作预设

| 平台 | 输出 | 宽度 / 模板 |
| --- | --- | --- |
| 淘宝 / 天猫、京东、拼多多、抖音电商 | 连续详情长图 + 切片 | 750px |
| AliExpress | 连续详情长图 + 切片 | 960px |
| 小红书 | 独立图卡 | 1242px |
| Temu | 独立图卡 | 1200px |
| Amazon A+ | 固定尺寸横幅模块 | Basic 970×300、Premium 1464×600 |
| Etsy | 保持原比例的实拍图库 | 2000px |
| TikTok Shop | 保持原比例的实拍图库 | 1200px |
| eBay | 保持原比例的实拍图库 | 1600px |
| Shopify | 品牌页面分区图片与文案 | 1536px |

这些是制作预设，不代表平台全部类目与全部上传位置的强制规格。Amazon 目前支持两种横幅，其他 A+ 模板需要另外制作。Etsy 定制、数字商品等例外需要按实际类目核对；本工具当前仅实现实物照片模式。实拍模式不推测原图是否真实拍摄，用户需选择实际商品照片。缩放至工作宽度也不会补回原图缺失的细节。

## 编排与导出

1. 上传照片，选择平台、市场和文案语言，录入已确认的商品事实。
2. 手动编辑或付费 AI 规划模块。AI 规划后的文案需人工核对，未知参数不进入最终文案。
3. 为模块指定实拍，或生成无字底图；编辑文字无需再次调用图片模型。
4. 调整模块顺序、启停和版式，查看同一渲染器生成的整页预览。
5. 导出上传包。长图平台默认按模块切片，也可指定固定高度；固定切点可能穿过图文，最后一片保留实际高度。图库、A+、Shopify 输出独立模块，长图只作可选预览。

文案溢出或任一启用模块缺图时阻止完整导出。切片直接从模块画布绘制，不要求先分配完整超长画布；完整 JPG 受浏览器画布能力影响，失败时仍可使用切片包。

ZIP 包含有序 JPG、`copy.txt`、`manifest.json` 和使用说明。草稿与版本保存在本机浏览器；生成图片优先缓存到本机，缓存失败会提示及时下载。尚未提供云同步、后台任务恢复或跨设备历史。

## 验收范围

浏览器测试使用明确标注的色块素材检查尺寸、跨模块切片、实拍不叠字、文字溢出与缺图拦截、草稿恢复和移动布局。这些测试图片不是 AI 成图样例。真实模型质量与卖家后台实际上传需另行验收。
